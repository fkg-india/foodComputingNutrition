# foodComputingNutrition

To run the code, download everything into a local folder, change file paths in cal_new.py (3 total, at the top of the file), run python cal_new.py in one terminal, python fastapi_frondend.py in another terminal, and it should be up and working.    

If you start running into nutritionix rate limit errors, just make another API key (here https://developer.nutritionix.com/) and update x-app-id, x-app-key params in the nutritionix function in cal_new.py

Please commit to new branches for any updates you might make to these files
